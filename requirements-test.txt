# What the TEST SUITE needs, and nothing else.

# Deliberately not "everything the project imports". Running the simulation
# additionally wants PX4, Gazebo Garden and ROS 2 Humble, none of which come
# from pip and none of which the tests touch - the tests cover geometry,
# perception and the state machine, all of which run on a bare machine.
#
# ⚠️ ultralytics/torch is NOT here on purpose. perception.py imports YOLO
#    lazily, inside the function that needs it, so nothing in the test path

#    for code no test executes.
#
# ⚠️ pyzbar needs a SYSTEM library, not just the wheel:
#        sudo apt-get install libzbar0
#    Without it the import succeeds and the first decode fails at runtime.
#
# Verified in a clean virtualenv on 2026-08-06: these alone give 43 passed.

numpy>=1.24,<2            # cv_bridge in the sim is built against numpy 1.x
